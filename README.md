# Özkan Ofset

Özkan Ofset web sitesi ve yönetim uygulaması.

## Çalıştırma

Node.js 22 veya üzeri gerekir. Haricî npm bağımlılığı yoktur.

```sh
npm start
```

Canlı ortam kurulumu ve güvenlik ayarları için [yayın kılavuzuna](deployment/YAYIN-KURULUM.md) bakın.

## Dosyalar ve yayın

Bu depo uygulama kodlarını içerir. Müşteri kayıtları, parolalar, yerel araçlar ve büyük davetiye görsel arşivi Git dışında tutulur. GitHub tek başına çalışan bir site yedeği değildir; ilk kurulumda temiz yayın paketindeki katalog verileri ve görseller de FTP ile aktarılmalıdır.

Canlı müşteri verilerini ve `.env` dosyasını güncelleme sırasında koruyun.
